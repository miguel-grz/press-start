# Sources

Every date, spec, price and sales figure on the site is backed by an entry here. Data entries in
`src/data` reference these sources by id. A figure that cannot be verified is flagged as uncertain
in the data and in the UI. It is never presented as fact.

_Research starts with the NES vertical slice (Phase 2). Until then catalog entries are marked `draft`
and show a "Facts pending sources" sticker._
